# Go CRUD App

Simple CRUD application built using:

* Go
* Gin
* HTML
* CSS
* JavaScript

This project was created for learning Go backend development and basic full-stack concepts.

---

# Run Backend

Go to backend folder:

```bash
cd backend
```

Install dependencies:

```bash
go mod tidy
```

Run server:

```bash
go run .
```

Backend runs on:

```text
http://localhost:8080
```

---

# Run Frontend

Open:

```text
frontend/index.html
```

in your browser.

---

# Features

* Add User
* Show Users
* Update User
* Delete User
